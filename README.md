# TorrServer TV Remote for Lampa

Запускайте домашний TorrServer с пульта телевизора. Компьютер остаётся без открытого окна команд, а на телевизоре достаточно нажать «Запустить и открыть Lampa».

Автор проекта — w1thoutmates.

## Что понадобится

- Компьютер с Windows 10/11, 64-разрядной системой и правами администратора для установки.
- Телевизор или приставка с Android TV / Google TV (Android 6 или новее).
- Оба устройства в одной домашней сети. Компьютер для пробуждения лучше подключить кабелем.
- Установленная Lampa на телевизоре. Кнопка открытия рассчитана на Android-приложение с именем пакета top.rootu.lampa. Другую сборку Lampa можно открыть вручную после запуска сервера.

TorrServer включается только по команде. После включения компьютера контроллер уже готов принимать команды. Входить в Windows для этого не нужно. Значок управления появляется после входа в Windows.

## 1. Подготовьте компьютер

1. Скачайте этот проект через зелёную кнопку Code → Download ZIP и распакуйте, например, в C:\TorrRemote. Папку после установки оставьте на месте.
2. Скачайте обычную Windows amd64-версию MatriX с официальной страницы TorrServer. Положите её рядом с Setup.cmd и назовите TorrServer-matrix-windows-amd64.exe. Если имя отличается, переименуйте скачанный файл. [Официальные загрузки TorrServer](https://github.com/YouROK/TorrServer/releases)
3. В параметрах Windows откройте «Сеть и Интернет», свойства домашнего подключения и выберите профиль «Частная сеть».
4. Дважды нажмите Setup.cmd. Выберите подключение, через которое компьютер соединён с домашним роутером. Нажмите «Установить» и подтвердите запрос Windows.
5. Запишите адрес компьютера, который появится в конце установки. Адрес для Lampa заканчивается на :8090.

Установка выполняется один раз. Параметры сохраняются в network.xml рядом с программой. Если адрес компьютера изменился, потребуется обновить настройку компьютера и телевизора. Удобнее закрепить постоянный адрес для ПК в настройках домашнего роутера.

Если установщик пишет, что порт занят, закройте ранее запущенный TorrServer и его контроллер. Эта версия использует порты 8090 и 8091.

## 2. Установите приложение на телевизор

1. В скачанной папке откройте tv. Файл TorrRemote.apk — установщик приложения для телевизора.
2. Скопируйте его на USB-флешку и подключите её к телевизору. Откройте файл через файловый менеджер на ТВ. Файловый менеджер можно установить из магазина приложений телевизора.
3. Если Android попросит разрешить установку из этого источника, разрешите её файловому менеджеру и повторите установку.
4. Откройте «Торр Сервер». При первом запуске введите адрес компьютера из предыдущего шага, только цифры и точки.
5. Поля для пробуждения пока можно оставить пустыми. Сохраните настройки.

Пример адреса компьютера — 192.168.1.50. Это пример, у вас адрес будет свой. На экране ТВ есть карточка «Настройки» для изменения значений.

## 3. Подключите Lampa

1. В «Торр Сервер» нажмите «Запустить сервер».
2. Откройте Lampa, нажмите шестерёнку и найдите раздел TorrServer.
3. В основной адрес впишите http://АДРЕС-КОМПЬЮТЕРА:8090, заменив слова адресом своего ПК. Например, http://192.168.1.50:8090.
4. Если ваша версия Lampa предлагает проверку подключения, запустите её. При успехе появится версия MatriX.
5. Откройте доступную вам раздачу, выберите файл и начните просмотр.

Для связи с TorrServer используется встроенный раздел настроек Lampa. Дополнительный плагин управления сервером устанавливать не требуется. Описание раздела есть в справке Lampa. [Справка Lampa](https://github.com/yumata/lampa/wiki)

Поиск раздач зависит от сборки Lampa и подключённого источника. Если у вас ещё нет источника, получите адрес и инструкцию у его владельца. Для плагина обычно используется «Настройки → Расширения → Добавить плагин», куда вводится предоставленная владельцем ссылка, затем Lampa перезапускается. Для источника поиска может использоваться раздел «Парсер». Названия пунктов различаются между сборками. Этот проект предоставляет управление TorrServer и не включает каталог фильмов или сторонний сервис поиска.

## Как пользоваться каждый день

Откройте «Торр Сервер» и нажмите OK на большой карточке «Запустить и открыть Lampa». После просмотра вернитесь и выберите «Остановить сервер».

Стрелки перемещают выделение. Короткое OK выполняет действие. Долгое OK на любой карточке открывает голосовой ввод. Можно сказать «Включи сервер», «Останови сервер», «Перезапусти сервер» или «Открой Лампу». Голосовой ввод зависит от наличия распознавания речи на вашем ТВ. Физическая кнопка микрофона на некоторых пультах вызывает системного помощника.

На компьютере значок планеты возле часов открывает те же команды. «Выход» закрывает значок. Контроллер продолжает работать.

## Если компьютер спит

В настройках приложения на ТВ укажите MAC-адрес проводного сетевого адаптера ПК. Его можно посмотреть в свойствах подключения Windows, поле «Физический адрес».

В свойствах адаптера в диспетчере устройств включите Wake on Magic Packet и разрешите адаптеру пробуждать компьютер. В настройках UEFI компьютера может также требоваться Wake on LAN / PCIe.

Для большинства домашних сетей поле широковещательного адреса можно оставить пустым. Для сети с другой маской укажите её широковещательный адрес вручную. Кнопка «Разбудить ПК» отправляет сигнал пробуждения. Кнопка запуска также пробует пробудить недоступный компьютер и ждёт около минуты. Поддержка зависит от компьютера, адаптера и роутера.

## Если что-то не работает

- Нет связи — проверьте, что ПК включён, адрес совпадает, сеть Windows частная и устройства находятся в основной домашней сети. Гостевая Wi-Fi-сеть часто изолирует устройства.
- Сервер запустился, а Lampa не открылась — откройте свою Lampa вручную. Возможна другая Android-сборка.
- Голос распознан неверно — используйте «Включи сервер» или обычные кнопки.
- При запуске установщика ошибка — проверьте наличие файла MatriX рядом с Setup.cmd и доступность портов.
- Журналы на компьютере находятся в controller.log и matrix.log.
- Управлять может любое устройство в разрешённой домашней подсети. Используйте доверенную домашнюю сеть.

Для проверки состояния откройте PowerShell в папке установки и выполните:

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Manage.ps1 Status
~~~

Для удаления сначала остановите сервер, затем выполните:

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Manage.ps1 Uninstall
~~~

Приложение телевизора удаляется через обычные настройки Android. Файлы сервера и база сохраняются в папке компьютера.

## Для желающих собрать самостоятельно

Windows-программы собирает Build.ps1 с помощью установленного в Windows .NET Framework. Setup.cmd делает это автоматически.

Для APK нужны JDK, Android SDK Platform 34 и Build Tools 35.0.0. Скрипт tv/Build.ps1 использует ANDROID_HOME, TORR_TV_KEYSTORE и TORR_TV_KEY_PASSWORD. Ключ подписи храните отдельно. Одна подпись нужна для установки будущих обновлений поверх существующего приложения.

Личные настройки сети, журналы, базы и ключи подписи исключены из Git. TorrServer и Lampa распространяются их авторами отдельно.

Публичная версия прошла сборку Windows-программ и APK, проверку подписи APK и проверку ограничений подсети. Установка на чистом ПК и новом телевизоре пока не проверена.
